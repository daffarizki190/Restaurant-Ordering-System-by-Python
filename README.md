## Deskripsi

Program pemesanan restoran berbasis CMD/Terminal bernama **Warung Nusantara**.  
Mensimulasikan alur pemesanan dari pilih menu hingga proses pembayaran.

## Fitur

- Tampilkan menu (Makanan, Minuman, Dessert)
- Tambah pesanan berdasarkan ID menu
- Lihat keranjang beserta estimasi total
- Ubah quantity item
- Hapus item dari keranjang
- Checkout dengan diskon bertingkat + pajak 10%
- Hitung kembalian otomatis
- Riwayat pesanan

## Diskon Otomatis

| Total Belanja | Diskon |
|---------------|--------|
| >= Rp 200.000 | 15%    |
| >= Rp 100.000 | 10%    |
| >= Rp  50.000 |  5%    |
